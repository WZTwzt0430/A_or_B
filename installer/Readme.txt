A_or_B /《只有两个按钮》
========================================

一款 Windows 控制台文字冒险游戏。

【故事】

你在一部电梯里醒来。金属墙壁，头顶一盏灯在闪。
控制面板上只有 A 和 B 两个按钮，没有楼层数字，没有开门键，也没有警铃。
你不记得自己是怎么进来的。

按 A，门开在 B3 地下停车场；
按 B，门开在顶楼。
两处都能走到一些地方，也都能走到尽头。
如果走得够深，你会发现面板上多了一个没有标记的按钮。

共 7 个场景、4 个结局。

【操作】

  A / B / C / D   选择对应选项
  ESC             打开退出菜单（保存并退出 / 直接退出 / 继续游戏）

【存档】

  主动保存    退出时选「保存并退出」，进度写入 save.sav
  自动备份    游戏进行中每 10 分钟把进度备份到 save.bak
  异常退出    下次启动会提示「检测到上次游戏未正常退出」，
              并优先从较新的那份备份恢复
  存档位置    安装版：%LOCALAPPDATA%\A_or_B\
              便携版：程序目录下的 data\ 文件夹

【日志】

  logs\ 目录下每次启动都会生成一个新的日志文件。
  遇到闪退、卡住、存档异常时，把这个目录里的日志发给开发者即可定位。

【卸载】

  设置 → 应用 → 已安装的应用 → A_or_B → 卸载
  卸载界面有「同时删除个人文件（存档）」复选框，默认不勾选，存档会保留。
  卸载完成后安装目录（含卸载程序自身）会被整个删除。
